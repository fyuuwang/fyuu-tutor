Fyuu Tutor UI v2 · Production asset

Component catalog

Every approved component with copy-ready HTML and slot rules. Page skeletons are in lesson.html / practice.html / reference.html. Assembly rules are in the project UI-CONTRACT.md. Component classes may only come from this catalog.

A · Map components

Goes in map-section, as the first-viewport map.

learning-map · Topic map

2-6 nodes around a central hub. Each map-node href must point to a same-page scene id. Modifiers --why / --govern / --build / --owner / --environment are examples; use data-component="learning-map" on the container.

<div class="learning-map" data-component="learning-map" aria-label="[topic]">
  <div class="map-hub"><strong>[center]</strong><span>[position]</span></div>
  <a class="map-node map-node--why" href="#scene-1"><strong>[Q1]</strong><span>[hint]</span></a>
  <a class="map-node map-node--govern" href="#scene-2"><strong>[Q2]</strong><span>[hint]</span></a>
</div>

relation-net · Concept network

Capability and certification only. Shows how concepts connect. Hub node uses --hub modifier.

<div class="relation-net" data-component="relation-net">
  <div class="relation-node relation-node--hub"><strong>[core]</strong><span>[desc]</span></div>
  <div class="relation-node"><strong>[concept]</strong><span>[desc]</span></div>
</div>

B · Case narrative components

Goes in case-section, following one thread.

Each scene matches a map-node anchor. scene-body can contain h3, paragraphs, structured components and takeaway.

  <div class="scene-number">01</div>
  <div class="scene-body">
    <h3>[title]</h3><p>[narrative]</p>
    <p class="takeaway">[conclusion]</p>
  </div>
</article>

takeaway · Conclusion

<p class="takeaway">[one-line conclusion]</p>

quick-check · Inline check

Default collapsed. Not counted in formal question bank.

<details class="quick-check">
  <summary>Check: [question]</summary>
  <p>[answer and reason]</p>
</details>

worked-example · Step-by-step

Capability and certification. Numbered problem-solving steps.

    <div class="worked-step-body"><p>[step]</p></div></div>
</div>

F · Questions and reference

Formal questions use JSON in a script tag; reference uses reference-grid.

quiz-section · Question area

Questions are declared as strict JSON. JS renders them. Four types: single_choice, flashcard, true_false, and matching.

<section class="quiz-section" id="practice">
  <div class="quiz-toolbar">
    <span id="scoreText">Answered 0 / 0</span>
    <button class="reset-button" id="resetQuiz" type="button">Reset</button>
  </div>
  <div id="quiz"></div>
</section>
<script id="lesson-questions" type="application/json">
[
  {"id":"LESSON-0001-Q001","type":"single_choice",
   "stem":"[stem]","options":["A","B","C","D"],
   "answer":0,"rationale":"[why]"},
  {"id":"LESSON-0001-F001","type":"flashcard",
   "stem":"[prompt]","answer_text":"[answer]"},
  {"id":"LESSON-0001-T001","type":"true_false",
   "stem":"[statement]","answer":false,"rationale":"[why]"},
  {"id":"LESSON-0001-M001","type":"matching",
   "stem":"[match prompt]",
   "pairs":[{"left":"a","right":"1"},
           {"left":"b","right":"2"},{"left":"c","right":"3"}],
   "rationale":"[why]"}
]
</script>

G · Reference structure

Used inside reference-section for multi-section reference pages.

chapter-header · Section grouping

Replaces scene inside reference pages. Number + title + one-line description. Use once per reference-section that represents a chapter or domain group.

<div class="chapter-header" data-component="chapter-header" id="ch1">
  <span class="chapter-number">01</span>
  <div class="chapter-header-body">
    <h2>[Chapter title]</h2>
    <p>[One-line description]</p>
  </div>
</div>

section-index · Chapter navigation

Two or three sticky tabs for reference pages with at least three chapters. Place inside lesson-shell before the header. Each target must exist as an id and match the data-stage of every chapter in that tab; JavaScript switches tabs with aria-current.

<nav class="section-index" aria-label="Section navigation">
  <a href="#domain-a" class="section-index-link">01 · [Domain A]</a>
  <a href="#domain-b" class="section-index-link">02 · [Domain B]</a>
</nav>
