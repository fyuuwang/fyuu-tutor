# Security policy

Report vulnerabilities through GitHub's private security-advisory feature. Do not attach private learning materials, learner records, credentials, or copyrighted sources to a public issue.

The latest `v0.1.x` release is supported during the preview period. Fyuu Tutor reads and writes local project files, so path-boundary escapes, unintended source modification, private-data publication, and claim-protocol bypasses are security-relevant.
