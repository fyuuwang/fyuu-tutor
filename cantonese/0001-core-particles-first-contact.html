沿案例走

拆解對話 - 初次接洽

課本第四課口語 1-5 句。每句點 🔊 聽發音。注意小詞的粵語用法。

01

唔該畀份介紹貴公司嘅資料我啊！

m4goi1bei2fan6gaai3siu6gwai3gung1si1ge3zi1liu2ngo5aa3

麻煩給我一份貴公司的介紹資料！

嘅 ge3
= 的
唔 m4
= 不（唔該 = 麻煩了/請）

「嘅」= 的；「唔」= 不。唔該 = 麻煩/請。

想一想：這句裡「嘅」連接什麼？

嘅連接名詞（貴公司嘅資料），唔構成否定（唔該 = 請/麻煩）。

02

目錄上已經列出咗我公司嘅所有商品，貴公司可能會對啲新產品更有興趣。

...lit6ceot1zo2...ge3...di1san1caan2ban2...

目錄上已經列出了我公司的所有商品，貴公司可能對這些新產品更感興趣。

咗 zo2
= 了（完成標記）
啲 di1
= 這些 / 一些

咗 = 完成；啲 = 這些/一些。

03

你好，李生！從廣告知道貴公司經營輕工產品嘅，好希望同你地建立業務關係。

...ging1ying4...ge3...nei5dei6gin3laap6yip6mou6gwaan1hai6...

你好，李先生！從廣告上得知貴公司經營輕工產品，很希望和你們建立業務關係。

嘅 ge3
= 的（「經營...產品嘅」省略名詞）
你地 nei5dei6
= 你們（地 = 哋 = 複數後綴）

嘅可省略名詞；你地 = 你們。

04

我地係經銷變速車配件呢行做咗十幾年。唔算好耐，但係係行內好有口碑嘅。

...hai6...zo2...m4syun3...

我們經銷變速車零件這行做了十幾年。不算很久，但是在行業內口碑很好。

係 hai6
= 是（粵語「是」）
咗 zo2
= 了
唔 m4
= 不

係 = 是；注意「變速」的速讀 cuk1。

05

我地做紡織品呢行好耐，計起黎都有五十年啦，係市場無人都話唔識我地公司嘅。

...laa1...m4sik1...ge3

我們做紡織品這行很久了，算起來有五十年了，在市場上無人不知我們公司。

唔 m4
= 不（唔識 = 不認識/不知道）
啦 laa1
= 了（語氣完成，比「咗」更口語）

唔可用在動詞前（唔識 = 不知道）；啦 = 了（語氣完成）。

同場景新對話 - 廣州家具展

教師自編，同樣講「初次接洽」，換成家具行業。先讀一遍，注意小詞的位置。

A（買家）

你好！唔該畀份你公司嘅家具目錄我睇下啊！

B（賣家）

冇問題。目錄上已經列出咗我公司嘅新系列，你可能對啲實木設計更有興趣。

A（買家）

我地係專做酒店家具採購嘅。從網上知道貴公司出口到歐洲，好希望同你地建立合作關係。

B（賣家）

我地做實木家具呢行做咗廿幾年，雖然唔算最大，但係行內好有口碑嘅。

A（買家）

咁就好啦。我地想搵啲長期合作嘅供應商。

做題驗證

主動輸出 - 先想再對答案

看普通話，心裡換粵語，再點開對照答案和粵拼。

1. 這是我們公司的介紹資料。

呢個係我哋公司嘅介紹資料。

ni1go3hai6ngo5dei2gung1si1ge3gaai3siu6zi1liu2.

2. 我們公司做了很多年了。

我哋公司做咗好多年啦。

ngo5dei2gung1si1zou6zo2hou2do1nin4laa1.

3. 這些新產品挺不錯的。

啲新產品唔錯。

di1san1caan2ban2m4co3.

4. 他們在業內口碑很好。

佢哋係行內好有口碑嘅。

keoi5dei2hai6hong4noi6hou2jau5hau2bei1ge3.

回話練習：客戶說「你好，可以畀份你哋公司嘅產品介紹我嗎？」

當然可以！呢度有我哋公司嘅全部目錄，你對邊類產品最有興趣？

dong1jin4ho2ji3! ni1dou6jau5ngo5dei2gung1si1ge3cyun4bou6muk6luk6, nei5deoi3bin1leoi6caan2ban2zeoi3jau5hing3ceoi3?
