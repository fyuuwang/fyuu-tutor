三种用途，一套稳定的学习界面

Agent 不再为每一课重新设计页面。它只判断课程用途与知识领域， 然后从固定格式、主题和组件中组合。

格式
授课、练习、速查
主题
总览、人员、过程、业务、复习
状态
UI v2

固定主题

颜色表达知识位置，不表达 Agent 个性

Page 是刷题背景，Primary 负责装饰和结构，Deep 负责文字、焦点和白字承载面。 正确与错误不随主题变化。

固定格式

不同学习任务使用不同设计语言

Lesson · 普通授课

干净中性画布，用地图、关系、编号和贯穿案例建立理解。

只有答题区进入莫兰迪练习语言。

Practice · 刷题训练

莫兰迪背景承托白色题卡，选项、计分、重做和反馈位置固定。

答对与答错同时显示文字，不只依赖颜色。

Reference · 知识速查

信息密度更高，适合公式、边界表和知识地图。

不强行加入完整三阶段授课流程。

有限组件

Agent 负责选组件，不负责发明组件

建立结构

地图、价值链、判断路径、比较矩阵、关系网。

讲清边界

边界对照、结论提示、即时检查。

保留依据

ECO 与来源包进入默认折叠的审计区。

验证学习

统一题卡、文字反馈、计分与重做。
