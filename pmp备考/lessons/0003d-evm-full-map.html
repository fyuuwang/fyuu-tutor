EVM 完整地图：上半边 + 下半边，一张图走完

每个缩写都拆开：英文全称加中文。先破解字母，再看上半边快照，最后沿 CPI 走下半边预测。

先破解“字母乱码”：9 个字母密码表

所有 EVM 缩写都是下面这 9 个字母拼出来的。记住它们，任何缩写你都能自己拆。

字母 英文 中文 记忆钩子
E Earned / Estimate 挣 / 估算 Earning 挣到；Estimate 估个数
V Value / Variance 价值 / 偏差 Value 值多少；Variance 差了多少
P Planned / Performance 计划 / 绩效 Plan 计划；Performance 干得咋样
A Actual / At 实际 / 在…时 Actual 真实的；At completion 完工时
C Cost / Completion 成本 / 完工 Cost 钱；Completion 干完
B Budget 预算 Boss 老板批的钱
S Schedule 进度（时间） 秒表，看时间
I Index 指数 I 长得像 1，及格线就是 1
T To 去 / 还要 To Complete = 还要干的

自己拆一个试试：EAC = Estimate（估算）+ At completion（完工时）+ Completion = “完工时的估算”，即总共要花多少。会拆字母，就不会看成乱码。

上半边：现在的快照（EV 当主角）

BAC 坐镇最顶上，下面所有数最后都要拿来跟它比。EV 坐中间，左比 PV、右比 AC。

缩写 全称 关系 / 一句话
BAC Budget At Completion · 完工预算 整个项目从头做到尾总共批了多少钱。立项签字起定死、永不改变，是头顶的预算天花板。
EV Earned Value · 挣值 你已经挣到的价值（干完的活按预算值多少）。站 C 位：左比 PV、右比 AC。
PV Planned Value · 计划价值 到现在这个时间点，计划该干完多少价值的活。P = Plan。
AC Actual Cost · 实际成本 到目前为止实际花了多少钱。A = Actual。只记账，不判断好坏。
SV / CV Schedule / Cost Variance · 偏差 SV = EV − PV（进度偏差），CV = EV − AC（成本偏差）。及格线 0：大于 0 好，小于 0 坏。
SPI / CPI Performance Index · 绩效指数 SPI = EV ÷ PV（看时间快慢），CPI = EV ÷ AC（看钱值不值）。及格线 1：大于 1 好，小于 1 坏。

下半边：从 CPI 往下走，预测未来要花多少

成本效率（CPI）决定整条预测链。顺着箭头：BAC ÷ CPI 得 EAC，再往下得 ETC 与 VAC。

缩写 全称 公式 / 一句话
EAC Estimate At Completion · 完工估算 总共要花多少（含已花的）。照现在 CPI 烧下去 = BAC ÷ CPI。A = At completion（完工时·总共）。
ETC Estimate To Complete · 完工尚需估算 还要花多少（不含已花的）= EAC − AC。T = To complete（还没干的·还要）。
VAC Variance At Completion · 完工偏差 预算与实花的差额 = BAC − EAC。大于 0 省钱，小于 0 超支。回答“最后到底超不超预算”。

记忆三个字：总、还、差。EAC = 总共要花，ETC = 还要花，VAC = 差多少。

EAC vs ETC：一个字母之差（最容易混）

EAC 和 ETC 只差中间一个字母。认出那个字母，就知道问的是“总共”还是“还要”。

EAC（A = At completion） 完工时·总共。含已经花的。问“整个项目最后一共要花多少”。
ETC（T = To complete） 还没干的·还要。不含已花的。问“从现在起还要再花多少”。

一句话串起来：EAC = AC + ETC（总共 = 已经花的 + 还要花的）。

用手指走一遍：代入 100 万的例子

设定：你负责上线客户管理系统，BAC = 100 万。项目过半，挣值 EV = 40 万，实际花了 AC = 50 万，计划此时该挣 PV = 45 万。

第一步：从 EV 起步

你已经挣到的 40 万，站 C 位。

第二步：往左比 PV

SV = 40 − 45 = −5 万（负＝进度落后）；SPI = 40 ÷ 45 ≈ 0.89（小于 1＝慢）。

第三步：往右比 AC

CV = 40 − 50 = −10 万（负＝超支）；CPI = 40 ÷ 50 = 0.8（每花 1 块只挣 0.8，亏）。

第四步：从 CPI 往下走

EAC = BAC ÷ CPI = 100 ÷ 0.8 = 125 万（照这样烧，总共要花 125 万）。

第五步：EAC 到 ETC

ETC = EAC − AC = 125 − 50 = 75 万（还要再花 75 万）。

第六步：BAC − EAC = VAC

100 − 125 = −25 万（负＝预计超支 25 万，老板要追问了）。

一句话记住整张图

BAC 是头顶的天花板；EV 坐中间，左 PV 右 AC，比出 SV/CV 和 SPI/CPI；从 CPI 往下走，BAC ÷ CPI 得 EAC（总共），减去 AC 得 ETC（还要），BAC 减 EAC 得 VAC（差多少）。
